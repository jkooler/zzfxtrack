        ZzFXMicro Music

        With this app you can create musical content using ZzFXMicro.js synthesis with Strudel REPL interface or Arranger.

        Export your creations as JSON files and use them in your games or other projects using the ZzFXMicro Player.

        NOTE: The exported JSON is not compatible with the canonical ZzFXM player. It targets the ZzFXMicro Player, which uses the 21-parameter ZzFXMicro format rather than the original ZzFM engine.
        Select an arrangement from the Blocks list to open the arranger workspace.

            About
          
          
          
        
          

        
          
          
          
            ZzFXMicro Music is an authoring/export tool for the bundled ZzFXMicro Player that embeds Strudel for its REPL workflow and Arranger. It focuses on exporting engine-friendly song data and making it fast to iterate on patterns and instruments.
          
          
          
          
            ZzFXMicro Music is an independent project and is not affiliated with or endorsed by Frank Force, KilledByAPixel, or the ZzFXM authors.
          
          

          
          
            
          Quick start
          
            
            
              
          1. Select Arrangement or Strudel pattern from the left sidebar and hit play.
            2. 
              
          2. Choose instrument that is playing and change it's parameters.
            3. 
              
          3. Try to make changes to the Arrangement/Blocks or Strudel pattern.
            4. 
              
          4. Note: Arrangements/Blocks and Strudel patterns aren't integrated, they are separate resources
            5. 
              
          5. Click Export ZzFXMicro and preview playback.
            6. 
              
          6. Open Song Data to inspect/download JSON, or click Export WAV to share/test.
            7. 
            
          
          
          

          
          
            
          How it fits together
          
            
            
              
          • Arranger: tracker-style workflow for composing loops with blocks.
            • 
              
          • Strudel: pattern notation and event scheduling.
            • 
              
          • ZzFXMicro: instrument parameter model and sound generation (registered as Strudel sounds for playback).
            • 
              
          • ZzFXMicro Player: the export target format for games/apps.
            • 
            
          
          
          

          
          
            
          Alpha notes
          
            
            
              
          • Some Strudel features may preview fine but not export 1:1.
            • 
              
          • For best results, stick to simple, repeatable patterns and test with exported playback.

            Technical details
          
          
          
        
          
        
          
          
          
            This app is a browser-based composition and export tool. It combines Strudel as the pattern language and live-coding interface, ZzFXMicro as the synth engine for sound generation, and an export pipeline whose main output is ZzFXMicro Player-compatible song JSON.
          
          

          
          
            
          Composition UI and runtime
          
            
            
              
          • The editor is the embedded <strudel-editor> REPL component. When you press Play (or run code via Strudel shortcuts), Strudel evaluates your code and drives timing/scheduling in the browser.
            • 
              
          • Sound is produced by ZzFXMicro instruments: the app maps instrument definitions to ZzFXMicro parameters and uses them for preview playback and for export.
            • 
              
          • The app keeps a small amount of UI state (selected pattern, play state, export settings) and mirrors it into the sidebar, toolbar, and modals.
            • 
              
          • Auto-save is event-driven: changes are debounced to avoid excessive writes, but key actions (like leaving certain inputs) can trigger immediate saves.
            • 
            
          
          
          

          
          
            
          Project files
          
            
            
              
          • Patterns (Strudel files) are JavaScript modules stored under patterns/. A selected pattern is loaded into the editor and also used as the source of truth for export and playback.
            • 
              
          • Blocks are reusable patterns stored under blocks/. They can include an embedded trackerState object so the Tracker can re-open them for editing.
            • 
              
          • Arrangements live under arrangements/ and reference blocks, letting you build longer pieces out of smaller patterns.
            • 
              
          • Instruments are stored in instruments.js and mapped to ZzFXMicro parameters for both preview and export.
            • 
            
          
          
          

          
          
            
          Local API (dev server)
          
            
          
              During development, the app talks to a small local API exposed by Vite middleware (endpoints like /api/patterns, /api/pattern/<name>, /api/blocks, and rename endpoints). These endpoints read and write files in the project directories so your edits persist as real modules you can commit.
            
          
          
          

          
          
            
          Tracker and blocks
          
            
            
              
          • The Tracker modal is a lightweight step sequencer. When you save a block, it generates a Strudel pattern string and stores the underlying grid state (trackerState) for later edits.
            • 
              
          • When inserting a block into a pattern, the app can optionally keep the block BPM, and it passes the block’s row count so insertion can align musically.
            • 
            
          
          
          

          
          
            
          Export and preview
          
            
            
              
          • Export is the main feature: it turns your composition into a ZzFXMicro Player song array [instruments, patterns, sequence, BPM] (plus optional stats), designed to be deterministic and engine-friendly.
            • 
              
          • Preview uses the same exported ZzFXMicro Player structure and ZzFXMicro synthesis to let you verify the result before downloading.
            • 
              
          • Export WAV renders the exported song to PCM audio and encodes it as a WAV file (sample rate and bit depth are configurable in Export Settings).
            • 
            
          
          
          

          
          
            
          Using the standalone ZzFXMicro Player
          
            
          
              Exported JSON is for the ZzFXMicro Player, not the canonical ZzFXM player. To play songs in your game or project:
            
          
            
            
              
          1. Copy the packages/zzfxmicro-player/ folder from this repo into your project.
            2. 
              
          2. Import: import { playZzfxmSong, stopZzfxmSong } from './zzfxmicro-player/index.js'; (adjust path as needed).
            3. 
              
          3. Call playZzfxmSong(songData, audioCtx, onEnded?) with your exported [instruments, patterns, sequence, BPM] array and an AudioContext.
            4. 
            
          
            
          
              The player has no dependencies. See packages/zzfxmicro-player/README.md in the repo for the full API.
            
          
          
          

          
          
            
          Demo mode
          
            
          
              In demo mode, pattern management is read-only and edits are kept in memory for the session. You can still download a ZIP to move the project files into a local workspace.
