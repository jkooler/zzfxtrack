      Welcome to
      STRUDEL TO ZZFXM

      With this app you can create songs using ZzFXMicro.js synthesis and Strudel REPL interface.

      After creating your song, export it to JSON format and use it in your games or other projects that use ZzFXM.

      NOTE: Ensure your game or project uses ZzFXMicro (standard for ZzFXM).
      The parameter mapping differs from the full ZzFX library.

            Technical details
          
      
          
        
      
        
      
          
      
            This app is a browser-based composition and export tool. It combines Strudel as the pattern language and live-coding interface, ZzFXMicro as the synth engine for sound generation, and an export pipeline whose main output is ZzFXM-compatible song JSON.
          
      

          
      
            
      Composition UI and runtime
      
            
        
              
      • The editor is the embedded <strudel-editor> REPL component. When you press Play (or run code via Strudel shortcuts), Strudel evaluates your code and drives timing/scheduling in the browser.
        • 
              
      • Sound is produced by ZzFXMicro instruments: the app maps instrument definitions to ZzFXMicro parameters and uses them for preview playback and for export.
        • 
              
      • The app keeps a small amount of UI state (selected song, play state, export settings) and mirrors it into the sidebar and preview panel.
        • 
              
      • Auto-save is event-driven: changes are debounced to avoid excessive writes, but key actions (like leaving certain inputs) can trigger immediate saves.
        • 
            
      
          
      

          
      
            
      Project files
      
            
        
              
      • Songs are JavaScript modules stored under songs/. A selected song is loaded into the editor and also used as the source of truth for export and playback.
        • 
              
      • Blocks are reusable patterns stored under blocks/. They can include an embedded trackerState object so the Tracker can re-open them for editing.
        • 
              
      • Arrangements live under arrangements/ and reference blocks, letting you build longer pieces out of smaller patterns.
        • 
              
      • Instruments are stored in instruments.js and mapped to ZzFXMicro parameters for both preview and export.
        • 
            
      
          
      

          
      
            
      Local API (dev server)
      
            
      
              During development, the app talks to a small local API exposed by Vite middleware (endpoints like /api/songs, /api/song/<name>, /api/blocks, and rename endpoints). These endpoints read and write files in the project directories so your edits persist as real modules you can commit.
            
      
          
      

          
      
            
      Tracker and blocks
      
            
        
              
      • The Tracker modal is a lightweight step sequencer. When you save a block, it generates a Strudel pattern string and stores the underlying grid state (trackerState) for later edits.
        • 
              
      • When inserting a block into a song, the app can optionally keep the block BPM, and it passes the block’s row count so insertion can align musically.
        • 
            
      
          
      

          
      
            
      Export and preview
      
            
        
              
      • Export is the main feature: it turns your composition into a ZzFXM song array [instruments, patterns, sequence, BPM] (plus optional stats), designed to be deterministic and engine-friendly.
        • 
              
      • Preview uses the same exported ZzFXM structure and ZzFXMicro synthesis to let you verify the result before downloading.
        • 
            
      
          
      

          
      
            
      Demo mode
      
            
      
              In demo mode, song management is read-only and edits are kept in memory for the session. You can still download a ZIP to move the project files into a local workspace.
